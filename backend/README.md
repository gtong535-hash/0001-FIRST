# 📊 DevLog Google Sheets Backend (최신 개선판)

구글 스프레드시트를 회원 및 게시글 데이터베이스로 사용하는 Google Apps Script(GAS) 백엔드 시스템입니다.

## 🌟 핵심 특징
1. **시트 자동 감지 및 자동 생성**:
   - `users` 시트가 없으면, 비어 있는 기본 시트('시트1' 등)를 자동으로 `users`로 변경하고 헤더를 작성합니다.
   - 따라서 수동으로 시트 탭 이름을 바꾸지 않아도 첫 요청 시 100% 자동 초기화됩니다.
2. **독립형 / 연동형 스크립트 완벽 호환**:
   - 스프레드시트 안에서 열었든, 구글 드라이브에서 직접 만들었든 모두 정상 작동합니다.
3. **POST / GET 듀얼 API 지원**:
   - 브라우저 주소창이나 curl 등으로도 간편하게 헬스체크 및 테스트 가능합니다.

## 🚀 적용 및 배포 방법

1. 구글 스프레드시트의 **[확장 프로그램] → [Apps Script]**를 엽니다.
2. [`Code.gs`](./Code.gs) 전체 내용을 복사하여 붙여넣고 저장(`Ctrl + S`)합니다.
3. 우측 상단 **[배포] → [배포 관리]** 클릭
4. 연필 아이콘(수정) 클릭 → **버전: 새 버전** 선택 → **액세스할 수 있는 사용자: 모든 사용자(Anyone)** 확인 후 **[배포]** 클릭!
