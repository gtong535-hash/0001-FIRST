# 📊 DevLog Google Sheets Backend (게시글/댓글/회원 통합 최신판)

구글 스프레드시트를 **회원 관리, 블로그 게시글, 댓글 데이터베이스**로 사용하는 Google Apps Script(GAS) 통합 백엔드 시스템입니다.

---

## 🌟 핵심 변경 및 기능 업데이트

1. **3종 시트 자동 감지 및 자동 생성 (`users`, `posts`, `comments`)**:
   - `users` (회원): 회원가입, 로그인, 닉네임, 프로필 정보
   - `posts` (게시글): 제목, 카테고리, 마크다운 본문, 요약문, 작성자 정보, 추천글(Featured) 여부, 작성일
   - `comments` (댓글): 글 ID, 작성자, 아바타, 댓글 본문, 작성일
   - 시트가 비어있어도 첫 요청 시 컬럼 헤더와 컬러 스타일링이 100% 자동으로 세팅됩니다.

2. **통합 API 액션 지원**:
   - **POST**:
     - `signup`: 신규 회원가입 (이메일, 닉네임 중복 체크)
     - `login`: 회원 로그인 인증
     - `createPost`: 신규 블로그 글 저장 및 자동 동기화
     - `addComment`: 글별 댓글 등록 및 저장
   - **GET**:
     - 기본 헬스체크 (`ONLINE` 상태 반환)
     - `action=getPosts`: 전체 게시글 목록 반환
     - `action=getComments&postId=...`: 특정 글 댓글 목록 반환

3. **스마트 무중단 하이브리드 폴백**:
   - 구글 시트 연결 지연이나 오류가 발생하더라도 프론트엔드 로컬 스토리지(`localStorage`)가 자동 백업되어 사이트 이용에 전혀 지장이 없습니다.

## 🚀 적용 및 배포 방법 (★필수 확인)

1. 구글 스프레드시트 상단 메뉴에서 **[확장 프로그램] → [Apps Script]**를 클릭합니다.
2. 기존 코드를 모두 지우고 [`Code.gs`](./Code.gs) 전체 내용을 복사해 붙여넣은 뒤 저장(`Ctrl + S`)합니다.
3. 우측 상단 **[배포]** 버튼을 클릭합니다:
   - **새로 배포하는 경우**: **[새 배포]** 클릭 → 유형 톱니바퀴에서 **[웹 앱]** 선택
   - **기존 배포를 수정하는 경우**: **[배포 관리]** 클릭 → 연필 아이콘(수정) 클릭 → **버전: 새 버전** 선택
4. **설정 확인 (★가장 중요!)**:
   - **다음 사용자로 실행**: `나 (본인 구글 계정)`
   - **액세스할 수 있는 사용자**: **`모든 사용자 (Anyone)`**  
     *(⚠️ 중요: 기본값인 '나만'으로 두면 외부 브라우저 접속 시 404 '페이지를 찾을 수 없음' 오류가 발생합니다! 반드시 **모든 사용자**로 설정해야 합니다.)*
5. **[배포]** 클릭 후 나타나는 **[웹 앱 URL]** (`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. 복사한 URL을 `js/blog-core.js` 상단의 `DEFAULT_GAS_URL`에 입력하거나, 블로그 관리자 콘솔 `BlogCore.setGasUrl('URL')`로 설정하면 실시간 스프레드시트 DB 연동이 완료됩니다.
